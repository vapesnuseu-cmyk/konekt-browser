Built in

Sidebar

One icon rail for Speed Dial, the KONEKT panel, bookmarks, history, downloads and the shield — nothing buried in menus.

KONEKT panel

The full KONEKT network — messages, feed, market, wallet — docked beside your tabs, sharing the same login session.

Speed Dial

Your sites as big tiles on every new tab. Pin your own with the + tile; your most-visited fill in the rest.

Ad & tracker blocker

On by default, with a live counter on the shield. Domain-level list of pure adtech hosts, so sites and logins keep working.

Pop-out video

Float any page's video in a picture-in-picture window and keep watching while you browse somewhere else.

Real Chromium

Electron 37 / Chromium 138 does the rendering, with a clean Chrome user agent — every site behaves exactly as in Chrome.

Your account, synced

Create a KONEKT Browser account and your bookmarks, Speed Dial, history and settings follow you across desktop and phone — stored server-side, just like KONEKT.

Liquid Glass & themes

Dark, Light or a translucent Liquid Glass mode, seven accent colours and six wallpapers — on desktop and Android. Built-in “check for updates” keeps you current.

In the wild

And the rest of a real browser

  • Tabs: drag to reorder, middle-click to close, per-tab mute, Ctrl+1…9, Ctrl+Tab
  • Omnibox with history suggestions, search/URL detection, padlock indicator
  • Google, DuckDuckGo, Bing or Yandex search — your pick
  • Downloads manager with pause / resume / show-in-folder
  • Find in page with match counter, per-tab zoom, print
  • Permission prompts for camera, mic and location — with per-site remember
  • Popups open as tabs. Sessions restore on restart
  • Light theme, full-screen (F11), DevTools (F12), Chrome-style shortcuts

Install · Windows

Download the zip
KONEKT-Browser-win-x64.zip, ≈128 MB, hosted on GitHub Releases.
Unzip anywhere
Documents, Desktop, a USB stick — the folder is the whole install; no admin rights needed.
Run “KONEKT Browser.exe”
Pin it to the taskbar if it feels right. Your profile lives in %APPDATA%\KONEKT Browser.
“Windows protected your PC”? Expected — this build is not code-signed, so SmartScreen warns on first run. Click More info → Run anyway. Verify the download against the checksum below if you want certainty about what you're running.
SHA-256 · KONEKT-Browser-win-x64.zip3C0D8A1895F894FB3245F9F2E602E2997AC9C94E43D1FDE2573C136DEA2CD421

Requires 64-bit Windows 10 or 11.

Install · Android

Download the APK
Open this page on your phone and tap Android above, or move KONEKT-Browser-android.apk across — it's only ≈60 KB.
Allow the install
Tap the downloaded file. If Android asks, allow your browser or Files app to “install unknown apps” — a one-time per-app switch.
Open KONEKT Browser
It appears in your app drawer with the KONEKT icon, and registers as a browser you can set as default.
“Unknown app” / Play Protect prompt? Expected — the APK is self-signed and not distributed through Play. Tap More details → Install anyway (or enable installs for your file manager). Match the checksum below to be sure the file is intact.
